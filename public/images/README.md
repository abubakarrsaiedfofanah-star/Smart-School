# Public image assets

Keep source images in this directory, grouped by their use:

- `school-day/` contains the locally bundled photos used on the public landing page.
- Brand marks and app icons live in `public/` and `public/icons/` because the web app, manifest, and service worker use stable root URLs for them.

The `dist/` directory is generated by Vite during a build. Do not add copies of source images there; Vite copies the public assets into the build output automatically.
