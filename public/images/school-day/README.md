Public school-day photos
========================

These JPEG images are bundled locally with the public landing page so the page
does not depend on a third-party image host at runtime. They are illustrative
stock photos, not photos of SmartSchool customer schools.

Each image was downloaded from its Unsplash CDN photo URL, resized/cropped to
the displayed web dimensions, and saved as a JPEG. Unsplash's license allows
free commercial and non-commercial use; attribution is appreciated.
